Airline Booking System

A comprehensive management platform for airline tickets, flights, and booking workflows built with Django.

Project Overview

This system allows users to search for flights, book tickets, and manage their travel history. It features a robust administration panel for airline staff to manage schedules and passenger data.

Key Features

  • Real-time Flight Search
  • Secure User Authentication
  • Role-based Access Control
  • Automated E-ticketing
