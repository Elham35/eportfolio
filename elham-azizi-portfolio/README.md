# Elham Azizi — Advanced Portfolio

## Files
- `index.html` — Home / hero / skills / projects / contact
- `about.html` — Detailed About page / technical toolkit / timeline
- `assets/css/style.css` — Full visual system and animations
- `assets/js/app.js` — Typing effect, scroll reveal, progress bar, cursor glow, magnetic buttons
- `cv/Elham-Azizi-CV.html` — Editable CV page that can be downloaded as HTML

## Personal information to replace
Search the project for:
- `your.email@example.com`
- `+93 700 000 000`
- social media URLs
- `assets/img/profile.jpg`

Put your photo at:
`assets/img/profile.jpg`

To make the CV a real PDF download, replace `cv/Elham-Azizi-CV.html` with your final PDF and change the Home download link to that PDF filename.

## Run
Open `index.html` in a browser.

Bootstrap 5 and Font Awesome are loaded from CDN. For a fully offline version, download those libraries into an `assets/vendor/` directory and update the `<link>` / `<script>` paths.
