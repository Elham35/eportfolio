JU-Learn Mobile App

A dedicated mobile learning application for Jahan University students to access courses, materials, and academic notifications.

App Features

JU-Learn is designed to bring the university experience to the student's pocket. It provides a fast, reliable, and offline-capable platform for modern education.

Capabilities

  • Offline Learning Access
  • Push Notifications
  • Real-time Grade Updates
  • Interactive Assignments

Technologies
